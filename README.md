# LP CicloBarber

Landing page do CicloBarber (arquivo único `index.html`, sem etapa de build).

- Publicação: Cloudflare Pages ligado a este repositório (pasta raiz `/`, sem comando de build).
- `_headers`: cabeçalhos de segurança aplicados pelo Cloudflare Pages.
- Configurações da página (WhatsApp, formulário etc.) ficam no objeto `CONFIG` dentro do `index.html`.
- Este repositório é público: nunca coloque chaves, senhas ou tokens aqui.
